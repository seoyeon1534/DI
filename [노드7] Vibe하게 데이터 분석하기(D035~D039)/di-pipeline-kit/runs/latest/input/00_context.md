## 누가 이 분석을 필요로 하는가

본인. AIFFEL AI 데이터 인텔리전스 과정 수강 중이며, 성과 마케팅 실무 경력을 바탕으로 통계·인과추론·데이터 분석 역량을 포트폴리오화하려는 목적. 이 데이터셋 자체가 fictional dataset이므로, 실제 이해관계자(상사, 클라이언트)가 아니라 "SQL/EDA/분석 파이프라인을 얼마나 제대로 짤 수 있는가"를 보는 학습·포트폴리오 리뷰어(본인, 멘토, 혹은 채용 담당자)가 이 보고서의 독자에 가까움.

## 어떤 결정을 앞두고 있는가

<!-- 이 항목이 비어 있으면 @problem 이 3단계에서 멈춥니다. -->

- 아직 결정이 없고 현황 파악이 목적. (fictional dataset이라 "이 결과로 실제 채널 예산을 재배분한다" 같은 실무 결정은 성립하지 않음.) 대신 굳이 결정의 형태로 바꾸면 아래에 가까움:
  - **어느 대안을 택할지 고르는 것** — 예: "이 데이터로 어떤 분석 스토리(채널 효율 비교 / 세그먼트별 전환 패턴 / 캠페인 유형별 ROI)를 포트폴리오의 메인 결과물로 택할지"
  → 즉, 비즈니스 의사결정이 아니라 **"어떤 분석 결과를 최종 산출물로 낼지"**를 고르는 단계로 진행.

## 이미 알고 있는 것 / 이미 시도한 것

- 데이터셋의 컬럼 구성, 범주값 종류, 결측치 없음, 균등 분포/무작위 조합 특성은 위 "이 데이터가 무엇인지" 단계에서 이미 확인함 (재발견 불필요).
- 데이터가 Kaggle 공식 설명상 fictional dataset임을 확인함 → 상관관계·ROI 차이 등이 나오더라도 "실제 마케팅 인사이트"로 과잉 해석하지 않는다는 전제가 이미 서 있음.

## 이 데이터가 무엇인지

- **출처**: Kaggle "Marketing Campaign Performance Dataset" — 공식 설명에 **"This is a fictional dataset"** 라고 명시되어 있음. 즉 실제 기업/캠페인 데이터가 아니라 학습·실습용으로 만들어진 가상 데이터.
  → 이 데이터로 나온 수치(전환율, ROI, 채널별 성과 차이 등)는 **실제 비즈니스 인사이트로 해석하면 안 됨**. 분석 기법 연습, 파이프라인 구축, SQL/EDA 실습이 목적이지 "그래서 어느 채널을 늘려야 한다" 같은 실무 결론을 내리는 데는 부적합함.
- 200,000건, 2021-01-01 ~ 2021-12-31, 결측치 없음, `Campaign_ID` 중복 없음(1행 = 캠페인 1건)
- `Company`: 5개 값 — 공식 설명상 "가상 브랜드들의 조합"(fictional brands). 실존 기업 아님
- `Campaign_Type`(5종: Email/Influencer/Display/Search/Social Media)과 `Channel_Used`(6종: Google Ads/YouTube/Instagram/Website/Facebook/Email)는 서로 다른 축 — "캠페인 유형"과 "집행 채널"이 분리되어 있고 조합이 자유로움(예: 유형=Display인데 채널=Email인 행도 존재)
- `Target_Audience`(성별×연령대 5종)와 `Customer_Segment`(관심사 기반 5종: Health & Wellness/Fashionistas/Outdoor Adventurers/Foodies/Tech Enthusiasts)도 서로 다른 축
- `Location`: 미국 5개 도시 / `Language`: 5개 언어 — 도시-언어 조합에 지리적 개연성은 없어 보임(예: Houston에 Mandarin 캠페인 등 임의 조합)
- `Duration`: "15/30/45/60 days" 문자열 → 숫자 변환 필요
- `Acquisition_Cost`: "$16,174.00" 문자열 → `$`,`,` 제거 후 float 변환 필요
- `Conversion_Rate`(0.01~0.15), `ROI`(2.0~8.0): 공식 설명상 "캠페인의 수익성/성공을 나타내는 지표"라고만 되어 있고, 산출 공식(ROI가 배수인지, 무엇 대비 무엇인지)은 데이터에 정의되어 있지 않음
- `Clicks`, `Impressions`, `Engagement_Score`(1~10): 참여도 지표. 집계 단위(캠페인당 총합인지 일평균인지 등)는 데이터에 명시 없음
- **분포 특성**: 각 범주형 컬럼이 5~6개 값으로 거의 균등하게 반복되고 조합도 무작위에 가까워, 실제 로그에서 나타나는 자연스러운 편향(특정 회사가 특정 채널을 선호하는 등)이 보이지 않음 — 합성 데이터라는 공식 설명과 일치하는 패턴

## 답이 나와도 할 수 없는 것

- 데이터가 fictional이므로 어떤 결과가 나와도 **실제 예산 재배분, 채널 전략 변경 등 실무 액션으로 연결할 수 없음** — 산출물은 "분석 역량을 보여주는 리포트/포트폴리오"까지가 한계.
- 개인 실습 프로젝트 범위 — 별도 팀·예산·인프라(유료 BI 툴, 별도 서버 등) 투입 불가. BigQuery 무료/샌드박스 티어, 로컬 환경, 오픈소스 라이브러리 수준에서 해결 가능한 방식이어야 함.
- (수강 일정상 마감 기한이나 발표 형식 제약이 있다면 알려주시면 이 항목에 추가하겠습니다.)
