# Dashboard Design

## 색상은 여기서 정하지 않는다

**색상 토큰의 단일 출처는 `.claude/rules/design-system.md` 다.**
이 파일에 색상 값을 적지 않는다. 값이 필요하면 그 파일을 Read로 읽는다.

레퍼런스 킷은 같은 토큰을 rules · 두 개의 스킬에 각각 적어 두었고,
그 결과 세 문서의 카드 배경색이 서로 달랐다. 그 실수를 반복하지 않는다.

HTML·CSS·SVG 구체 패턴은 `references/design-tokens.md`를 Read로 읽어서 쓴다.

---

## 순서 — 이 순서를 지킨다

1. **원형을 고른다** (분해형 / 코호트형 / 판정형)
2. **독자를 정한다** — 누가 보는가, 무슨 결정을 내리는가
3. **와이어프레임을 텍스트로 쓴다** — 코드 전에
4. **차트를 고른다** — 각 차트에 "어느 질문에 답하는가" 를 붙인다
5. 템플릿을 복사해 채운다
6. 색은 마지막에 — rules의 토큰을 그대로

**색을 먼저 고르면 나쁜 차트가 나온다.** 형태가 먼저다.

---

## 원형 선택

| 원형 | 답하는 질문 | 핵심 시각 요소 |
|---|---|---|
| **분해형** | 전체가 움직였다. 누가 움직였나 | KPI 카드 → 정렬 막대 → 비중 → 산점도 |
| **코호트형** | 지금 있는가가 아니라, 시간이 지나도 남는가 | 삼각 히트맵 → 리텐션 커브 → 워터폴 |
| **판정형** | 차이가 있는가가 아니라, 이 차이로 결정해도 되는가 | 리프트+신뢰구간 → 누적 시계열 → 배정 점검 |

**원형이 다르면 문법이 다르다.** 코호트형에 막대 랭킹을 넣거나
판정형에 점 추정만 그리면 원형을 잘못 고른 것이다.

`templates/README.md`에 원형별 템플릿 상태가 적혀 있다.

---

## 차트 형태

| 목적 | 차트 | 주의 |
|---|---|---|
| 추세 | 라인 | 변동과 추세를 구분해 서술 |
| 범주 비교 | 정렬된 막대 | 정렬 기준을 제목에 밝힌다 |
| 구성 | 스택 막대 | 파이는 조각 3개 이하일 때만 |
| 분포 | 히스토그램 / 박스플롯 | 평균만 찍지 않는다 |
| 두 지표 관계 | 산점도 | 이상치가 상관을 만드는지 확인 |
| 시간 × 코호트 | 삼각 히트맵 | 행=코호트, 열=경과기간 |
| 불확실성 | 에러바 / 신뢰구간 | 판정형에서는 필수 |
| 단일 헤드라인 | 큰 숫자 (차트 아님) | 지표 하나면 차트를 만들지 않는다 |

**이중 축 금지.** 스케일이 다른 두 지표는 차트를 나누거나 공통 기준으로 지수화한다.
이게 가장 흔한 차트 실수다.

## 컴포넌트 스펙

### KPI 카드
- 레이블(흐림) → 수치(본문 잉크, tabular-nums) → 단위 → 증감
- **수치에 색을 쓰지 않는다.** 증감은 부호와 화살표로
- 스파크라인은 있으면 좋지만 축 없이, 끝점만 강조

### 차트 카드
- 순서 고정: 제목 → 한 줄 설명 → SVG
- 제목은 질문형 또는 결론형
- 카드 패딩 20px, 같은 행 카드는 높이 통일
- 넓은 차트는 자기 컨테이너에서 가로 스크롤

### 마크
- 선 2px · 마커 8px 이상 · 막대 끝 4px 라운드, 베이스라인에 고정
- 인접 채움 사이 2px 표면색 간격
- 겹치는 마크에 2px 표면색 링
- 직접 레이블은 선택적으로 — 모든 점에 숫자를 붙이지 않는다

### 범례
- 계열 2개 이상이면 항상. 4개 이하면 직접 레이블도 함께
- 계열 하나면 범례 없음 — 제목이 이름을 말한다

### 상호작용
- 라인·영역: 크로스헤어 + 툴팁
- 막대·점·셀: 마크별 호버 툴팁
- 히트 영역은 마크보다 크게
- 필터는 차트 위 한 줄에 모은다

---

## 접근성

- 색만으로 의미를 전달하지 않는다 — 범례 + 직접 레이블 + 상태 아이콘
- 표 보기를 제공한다 (마지막 탭)
- 다크 모드는 자동 반전이 아니라 별도 단계 — rules의 다크 토큰을 쓴다
- 키보드 포커스에 보이는 상태를 준다

---

## 금지

- CDN 차트 라이브러리 (Chart.js, D3, Plotly)
- 이중 축
- KPI 수치에 색상
- 유니코드 이모지 — 아이콘은 인라인 SVG
- 한쪽 변만 있는 border
- 한 탭에 차트 8개 이상
- 분석에 없는 지표 추가
- 색을 먼저 고르는 것
