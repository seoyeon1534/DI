# 대시보드 디자인 시스템

**이 파일이 색상 토큰의 단일 출처입니다.**
스킬 문서나 에이전트 파일에 색상 값을 다시 적지 않습니다. 여기를 가리킵니다.
(레퍼런스 킷은 같은 토큰을 세 문서에 각각 적어 두어 값이 서로 달라졌습니다.)

상세 HTML·CSS·SVG 패턴은 `.claude/skills/dashboard-design/references/design-tokens.md`.

**KPI 수치는 본문 잉크 색으로 고정한다. 수치에 색상을 쓰지 않는다.**
증감은 색이 아니라 부호와 화살표로 나타낸다.

## 계열색 — 순서 고정, 순환 금지

| 순서 | 라이트 | 다크 |
|---|---|---|
| 1 | `#2A5BD7` | `#3A68DE` |
| 2 | `#0092A8` | `#0092A8` |
| 3 | `#9B3FD1` | `#9B3FD1` |
| 4 | `#D6337F` | `#D6337F` |
| 5 | `#B5760B` | `#B5760B` |

- **순서대로 배정한다.** 계열이 하나 빠져도 남은 계열의 색을 다시 칠하지 않는다
- 색은 항목에 붙는다. 순위에 붙지 않는다
- 6번째 계열이 필요하면 새 색을 만들지 않는다 — "기타" 로 묶거나 차트를 나눈다
- 계열이 2개 이상이면 범례를 항상 넣고, 4개 이하면 직접 레이블도 함께 넣는다
  (색만으로 구분되게 두지 않는다)

이 다섯 색은 색각 이상 조건에서의 인접쌍 분리도(ΔE)와 표면 대비를 검증기로 확인한 값입니다.
**임의로 바꾸지 마세요.** 바꿔야 하면 검증기를 다시 돌려 통과를 확인한 뒤 이 표를 갱신합니다.

## 순차색 (크기)

한 색조의 명도 단계. 무지개 금지.
`#E8EEFA` → `#C3D3F2` → `#8FADE6` → `#5480D8` → `#2A5BD7` → `#1B3E96`

## 발산색 (양극)

두 색조 + 중간은 중립 회색. 중간에 색조를 두지 않는다.
`#D6337F` ← `#EFE9E2` → `#0092A8`

## 상태색 — 계열색으로 쓰지 않는다

| | 라이트 | 다크 |
|---|---|---|
| 좋음 | `#157F4F` | `#2FA26C` |
| 경고 | `#D9730D` | `#E8891F` |
| 위험 | `#C0392B` | `#DC5546` |

- 상태색은 **항상 아이콘 또는 레이블과 함께** 쓴다. 색만으로 상태를 전달하지 않는다
- 계열 5번(`#B5760B`)과 경고색(`#D9730D`)은 인접 색조다. 한 화면에 둘 다 나오면
  경고 쪽에 반드시 레이블을 붙인다

## 차트 규칙

- **순수 SVG 만 사용한다.** CDN 차트 라이브러리(Chart.js, D3, Plotly) 금지
- 축은 하나. **이중 축(두 개의 y축) 금지.** 스케일이 다른 두 지표는 차트를 나눈다
- 마크는 얇게. 선 2px, 마커 8px 이상, 막대 끝 4px 라운드
- 인접한 채움 사이에 2px 표면색 간격
- 격자와 축은 뒤로 물린다 — 경계색보다 연하게
- 숫자가 열로 정렬되는 곳에는 `font-variant-numeric: tabular-nums`
- 차트 텍스트는 계열색을 입지 않는다. 잉크 색을 쓴다

## SVG 여백

- 플롯 영역이 viewBox 면적의 **80% 이상**
- viewBox 여백: 상하 10, 좌우는 축 레이블 있으면 40~70 / 없으면 8
- `width:100%; height:auto` — 카드 너비에 맞춘다. 고정 height 금지
- 막대 좌표: `y = (1 - v/max) * h`, `height = (v/max) * h` (y=0이 상단)

## 레이아웃

- 카드 패딩 20px, 섹션 간격 28px 고정
- 메인 차트 행은 `1.5fr 1fr` — 모든 카드가 같은 너비인 배치는 지양
- 풀너비 차트는 탭당 1개
- 카드 계층: 메인 / 일반 / 보조(`opacity .75`) 세 단계만
- 넓은 표·차트는 자기 컨테이너에서 가로 스크롤. 페이지 본문이 옆으로 밀리지 않게

## 타이포

- 카드 제목: sans 700. **한글 포함 시 serif 금지**
- KPI 수치: sans 600, tabular-nums
- 차트 레이블·수치: monospace
- 본문 가로폭은 65자 내외

## 금지

- KPI 수치에 색상
- 이중 축
- 한쪽 변만 있는 border (`border-left` 단독)
- 유니코드 이모지 — 아이콘은 인라인 SVG
- 파이 차트(이유 없이), 3D 차트
- 한 탭에 차트 8개 이상
- 분석에 없는 지표를 임의로 추가
