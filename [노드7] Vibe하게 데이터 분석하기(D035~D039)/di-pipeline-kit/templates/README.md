# 대시보드 원형 템플릿

`@dashboard` 가 이 폴더에서 베이스를 고른다. **새 HTML을 처음부터 쓰지 않는다.**

## 원형이 다르면 문법이 다르다

| 원형 | 답하는 질문 | 파일 | 상태 |
|---|---|---|---|
| **분해형** | 전체가 움직였다. 누가 움직였나 | `base-decomposition.html` | ✅ 완성 |
| **코호트형** | 지금 있는가가 아니라, 시간이 지나도 남는가 | `base-cohort.html` | ⬜ 미작성 |
| **판정형** | 차이가 있는가가 아니라, 이 차이로 결정해도 되는가 | `base-verdict.html` | ⬜ 미작성 |

미작성 원형이 필요하면 분해형을 베이스로 쓰되, **무엇이 부족한지 보고한다.**
없는 것을 억지로 분해형에 끼워 넣지 않는다.

## 분해형 — `base-decomposition.html`

**대응 직무:** 퍼포먼스 마케터 · 그로스 마케터
**데이터 구조:** 범주 × 기간 집계. 지표는 대부분 파생

| 패널 | 내용 |
|---|---|
| 현황 | KPI 카드 5개 → 추세 라인(2계열) → 구성 스택 막대(5조각) |
| 원인 | 정렬 가로 막대(범주 비교) → 산점도(두 지표 관계) |
| 세부 | 액션 P1/P2/P3 → **이 결론이 틀렸다면** 카드 |
| 데이터 | 집계 표 (n 열 포함, n<5 마스킹 예시 포함) |

플레이스홀더 65개, `<!-- FROM: -->` 주석 9개.

**이 원형의 함정** — 지표 합산 시 이중계상(어트리뷰션 창 중복),
분모 오염(신규/재구매 혼입), 마진 미반영, 국내 % 표기와 글로벌 배수 표기 혼용.
대시보드 메타 줄에 집계 단위와 제외조건을 남기는 것으로 절반이 막힌다.

## 코호트형 — 만들 때 필요한 것 (미작성)

분해형에 없는 것:

- **삼각 히트맵** — 행=코호트, 열=경과기간. 데이터 없는 삼각 영역은 그리지 않는다.
  0으로 칠하면 "유지율 0%" 로 읽힌다
- **리텐션 커브 오버레이** — 코호트별 라인을 겹쳐 그린다. 계열이 6개를 넘으면
  최근 N개만 진하게, 나머지는 보조(`opacity .75`)
- **워터폴** — 기초 → 신규 / 확장 / 축소 / 이탈 → 기말
- 순차색 단계 (`rules/design-system.md` 순차색)

**이 원형의 함정** — Classic / Rolling / Unbounded 리텐션 정의 혼용,
24시간 창 vs 캘린더 날짜, Active 정의 표류, 1:N 조인으로 인한 금액 팽창.

---

## 판정형 — 만들 때 필요한 것 (미작성)

분해형에 없는 것:

- **리프트 + 신뢰구간 에러바** — 점 추정만 그리지 않는다.
  **0 기준선을 반드시 그린다.** 구간이 0을 지나는지가 판정의 핵심
- **누적 지표 시계열** — 조기 종료(peeking) 유혹을 화면 구조로 막는다.
  "표본 목표 도달" 표시가 없으면 매일 들여다보다 유의해진 순간 멈춘다
- **배정 점검 패널** — 실제 배정 비율 vs 의도 비율(SRM)
- **가드레일 지표 패널** — 주 지표가 올라도 이것이 떨어지면 중단

**이 원형의 함정** — peeking, SRM 미점검, 다중비교 미보정,
유의성과 임팩트의 혼동.

> 검정 이론은 통계 모듈 소관이다. 이 원형은 **판정을 화면으로 표현하는 법**만 다룬다.

## 공통 규칙

- 색상·타이포·여백은 `.claude/rules/design-system.md` 가 단일 출처
- 구체 패턴·SVG 좌표 계산은 `.claude/skills/dashboard-design/references/design-tokens.md`
- 템플릿의 CSS·JS·클래스 이름을 바꾸지 않는다. 플레이스홀더만 교체한다
- 분석에 없는 패널은 버튼과 섹션을 **함께 제거한다.** 빈 탭을 남기지 않는다
