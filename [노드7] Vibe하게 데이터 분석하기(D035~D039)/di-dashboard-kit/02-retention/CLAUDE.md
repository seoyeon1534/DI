# CLAUDE.md — 코호트 리텐션 & LTV 대시보드

## 이 프로젝트의 목표
`data/`의 구독 CSV를 받아, **이 폴더의 디자인을 그대로 따르는** 코호트 리텐션·MRR·LTV 대시보드 HTML을 `output/`에 만든다.
"예쁜 화면"이 아니라 "3초 안에 어떤 코호트가 새고 있고, 어디에 리텐션 자원을 넣을지 보이는 화면"을 만든다.

## 가장 중요한 규칙 (반드시 먼저 읽을 것)
**처음부터 새로 디자인하지 않는다.** 항상 `templates/reference.html`을 먼저 Read 하고,
그 **구조·레이아웃·색상·차트 종류·카드 패턴을 그대로 재사용**한 뒤, **숫자와 인사이트만 새 데이터로 교체**한다.

- 레퍼런스는 **"품질 기준선"** 이다. 결과물이 레퍼런스보다 단순하거나 다른 톤이면 실패다.
- 레퍼런스에 박힌 수치는 **전부 디자인용 예시**다. `⚠ SAMPLE` 마커가 붙은 블록은 **전량 교체 대상**이다.
  산출물에 레퍼런스 숫자가 하나라도 남아 있으면 실패다.
- 단, **복붙이 아니다.** 데이터는 반드시 새로 분석해서 실제 계산값을 넣는다 (아래 지표 정의대로).
- **JS 로직·차트 초기화·플러그인·배열 필드명/형식은 절대 바꾸지 않는다.** const 데이터의 **값만** 교체한다.
  (필드명·배열 길이가 바뀌면 차트가 깨진다.)
- 데이터로 계산할 수 없는 지표는 **만들어내지 않는다.** 컬럼이 없으면 진행을 멈추고 사용자에게 알린다.

## 색 사용 규칙 (PART 1 Ch 6 · 모두의연구소 브랜드)
색은 **네 가지 일 중 하나**를 할 때만 쓴다 — 분류 · 크기 · 강조 · 의미. 넷 다 아니면 장식이다.

| 역할 | 색 | 쓰는 곳 |
|---|---|---|
| 문제 · 하락 · 나쁜 예 | 코랄 `--c3 #C63B3F` | 이탈·위험·경고 지표, 강조 |
| 해법 · 좋은 예 · 결론 | 네이비 `--navy #31538F` | 목표선·기준선, 2번째 범주 |
| 정상 · 상승 | `--green #1B7F49` | 증가 뱃지, 양호 상태 |
| 주의 | `--amber #8A6100` | 중간 위험 |
| 중립 · 비활성 | `--t4 #8A8A94` | 나머지, 강조 대비용 |
| 잉크 | `--t1 #2B2B30` | 수치·사이드바 |

- **범주형**은 코랄 → 네이비 → 정상(녹) → 앰버 → 회색 순으로 **최대 5색**. 그 이상은 회색 + 직접 라벨.
- **연속형**(코호트 리텐션 등 순서 있는 값)만 **단일 색상 램프**를 쓴다.
  값이 클수록 좋은 지표는 **네이비 램프**(진할수록 좋음), 나쁠수록 큰 지표는 **코랄 램프**.
- **강조 채널은 한 차트에 하나.** 색으로 강조했으면 크기는 건드리지 않는다.
- 같은 변수는 차트가 바뀌어도 **같은 색**을 유지한다.
- 상태색(정상/주의/위험)은 **상태에만** 쓴다. 범주 구분에 전용하지 않는다.
- 색만으로 정보를 나르지 않는다 — 라벨·아이콘·값 표기를 함께 둔다(색각 이상 8%).
- `--coral #F7585C`는 대비 3.2:1이라 **큰 면·배경 전용**이다. 작은 글자·선에는 `--c3`를 쓴다.

## 핵심 KPI 정의 (계산식 고정)
| 지표 | 계산식 | 표기 |
|---|---|---|
| 코호트 리텐션율 | 해당 코호트의 M{n} 활성 유저 / M0 유저 × 100 | `%` |
| MRR | 해당 월 활성 유저 mrr 합계 | `₩…M` |
| 신규 MRR | 그 달에 처음 가입한(signup_month==active_month) 유저 mrr 합 | `₩…M` |
| Expansion MRR | 동일 유저 전월 대비 mrr 증가분 합 | `₩…M` |
| Churned MRR | 그 달에 churned=1 된 유저의 직전 mrr 합 (음수 표기) | `−₩…M` |
| Revenue Churn rate | 이탈 MRR / 전월 총 MRR × 100 | `%` |
| NRR | (기초MRR − churned + expansion) / 기초MRR × 100 | `%` |
| 평균 LTV | 유저별 생애 mrr 합의 전체 평균 (= ARPA / churn 근사) | `₩…K/M` |
| Payback(참고) | CAC / 월 ARPA (CAC 미제공 시 표기 생략) | `개월` |

- 비율은 `%`, 증감은 `%p`로 구분 표기. 절대값/상대값/누적값 혼용 금지.
- 코호트는 **가입월(signup_month) 오름차순** 행, **경과월(M0..Mn)** 열. M0는 항상 100%.
  `n`은 데이터가 지원하는 최대 경과월이다 — 샘플 데이터는 6개월이라 **M5까지**다.
  KPI 카드 라벨도 데이터에 맞춘다: 레퍼런스의 `M6 코호트 리텐션`은 예시이므로 **`M5 코호트 리텐션`으로 바꾼다.**

### ⚠ 기준월(reference month) 규칙 — 반드시 지킬 것
MRR·Churn·NRR·신규 MRR 같은 **월 단위 KPI는 "마지막 완전한 달"을 기준월로 쓴다.**
- 마지막 달에 `churned=1` 건수가 **0이면 집계가 아직 안 끝난 달**이다. 그 달을 기준으로 쓰면
  Revenue Churn이 0%, NRR이 100%를 넘어 **사실과 다른 결론**이 나온다.
- 판정 절차: 월별 `churned=1` 건수를 세고, **0인 마지막 달은 기준월에서 제외**한다.
  (샘플 데이터는 2024.06의 churn이 0건이므로 **기준월 = 2024.05**)
- 코호트 히트맵·LTV 분포는 전체 기간을 쓰고, **월 KPI만** 기준월을 따른다.
- 화면 어딘가에 `기준월: YYYY.MM` 을 반드시 표기한다.
- 아직 관측 안 된 (가입월 + 경과월 > 데이터 마지막 월) 셀은 `null` 유지 → 회색 빈 칸으로 렌더.
- **표본 가드**: 코호트 기준 인원이 50명 미만이면 히트맵 셀에 `표본 작음`을 표기한다.
- 플랜 세그먼트는 churn 낮은(리텐션 좋은) 순으로 색 `--c1`~`--c5` 부여.

## What-if (가정 변경 시 영향) 관점
- 대시보드는 슬라이더로 **churn / expansion / 신규 MRR** 가정을 바꿔 예측 MRR·NRR·3개월 포워드를 보여준다.
- `BASE_MRR`(현재 총 MRR), `BASE_NRR`(현재 NRR)을 실제 계산값으로 고정하면 What-if 로직이 그 위에서 돈다.
- 권고는 항상 "이 가정을 X로 바꾸면 MRR이 Y만큼 움직인다" 형태로 — 막연한 "좋아진다" 금지.

## 대시보드 구성 (reference의 섹션 순서 유지)
1. **상단 KPI 카드 6개**: MRR · **M{n} 코호트 리텐션**(데이터 최대 경과월) · 평균 LTV · Revenue Churn · 신규 MRR · NRR (각 스파크라인 포함)
   - 월 KPI 4종(MRR·Revenue Churn·신규 MRR·NRR)은 위의 **기준월 규칙**을 따른다.
   - 카드 제목/정의는 결론·기준형 ("이탈 MRR / 전월 MRR · 매출 기준")
2. **MRR 구성 추이** — 신규/확장/이탈 스택 막대 + 성장률 라인 (월별)
3. **What-if 시뮬레이터** — churn/expansion/신규 슬라이더 → 예측 MRR·NRR
4. **코호트 리텐션 히트맵** — 가입월 × 경과월 매트릭스 (chColor 색 규칙)
5. **이탈 사유 Pareto** — 건수 기준 / 매출 기준 토글
6. **LTV 분포** — 매출 구간별 고객 비중 히스토그램
7. **AI 인사이트 카드** — 이탈 위험·코호트 하락·매출 영향 순위 (결론+권장 액션)
8. **플랜 세그먼트 표** — 고객수·MRR·Churn·NRR·LTV·MoM·권장 액션 배지

## 금지
- reference를 무시하고 처음부터 새 레이아웃을 만드는 것
- 데이터 분석 없이 **레퍼런스 숫자를 그대로 남겨두는 것**
- **`Math.random()` 등으로 차트 데이터를 생성하는 것** (스파크라인·시계열 포함)
- const 배열의 **필드명·길이·형식을 바꾸는 것** / JS 로직 수정 (차트 깨짐)
- KPI 수치에 색 입히기 / 한쪽 변만 있는 border(border-left 등 단독)
- 차트 종류를 이유 없이 늘리기 / 장식용 그라디언트
- `:root` 토큰 밖의 색을 새로 만드는 것
- `%`와 `%p` 혼용 / 절대값과 상대값을 한 칸에 섞기
- 표본이 작은 구간을 단정적으로 해석하는 것 (표본 가드 문구를 붙인다)
- 글자를 11px 미만으로 줄이는 것 / 대비 3:1 미만인 색을 데이터 마크·텍스트에 쓰는 것
- 좁은 막대 **안쪽**에 값을 넣어 잘리게 두는 것 (안 들어가면 막대 밖 고정 칸으로)

## 이 킷에만 해당 (금지 보강)
- 코호트 M0를 100% 아닌 값으로 두거나, 미관측 셀을 0으로 채우는 것
- churn 집계가 끝나지 않은 마지막 달을 기준월로 쓰는 것
