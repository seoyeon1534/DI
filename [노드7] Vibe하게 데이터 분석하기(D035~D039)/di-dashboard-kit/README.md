# DI 대시보드 킷 — 직무별 실전 대시보드 5종

「Part 4. 직무별 실전 대시보드」 실습용 킷. **폴더 하나에 들어가 명령어 한 줄**이면
강사와 같은 퀄리티의 대시보드가 자기 데이터로 만들어진다.

```bash
cd 01-abtest           # 원하는 킷 폴더로
claude
/build-dashboard       # 끝
```

## 킷 하나의 구성

```
0N-xxx/
├── CLAUDE.md                       # 디자인 헌법 (토큰·지표 정의·구성 규칙)
├── .claude/skills/build-dashboard/ # 작업 절차 (이게 /build-dashboard 명령이 됨)
├── templates/reference.html        # 품질 기준선 = 강사의 완성 대시보드
├── data/*.csv                      # 샘플 데이터 (여기를 본인 것으로 교체)
└── output/                         # 결과물이 여기 생성됨
```

**세 축이 묶여 있어서 데이터만 바뀌어도 결과 퀄리티가 일정하다.**
CLAUDE.md = 규칙 / Skill = 절차 / reference.html = 기준선.

### reference.html 은 데이터와 별개다
레퍼런스에 박힌 숫자는 **디자인용 예시**다. `⚠ SAMPLE` 마커가 붙은 블록은 전량 교체 대상이며,
산출물에 레퍼런스 숫자가 남아 있으면 실패로 본다.

## 킷 하나만 있어도 됩니다
각 폴더는 **그 자체로 완결**입니다. 필요한 킷 폴더 하나만 받아서 그 안에서 `claude` 를 실행하면 됩니다.
`.claude/` 는 숨김 폴더이므로, 압축을 풀거나 복사할 때 **숨김 파일 포함**으로 다뤄야 `/build-dashboard` 명령이 살아 있습니다.

## 공통 규격
- 폰트 **Pretendard** (CDN) · 차트 **chart.js@4.4.0** (CDN)

- 비율 `%` / 증감 `%p` 구분 표기
