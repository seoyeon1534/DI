## 2. 「실수 5」 이후 나온 의문점과 확인 결과

### 2.1 마지막 수요일 적중률 0.49 와 예측 지평

- 0.49 는 `확정 == '전날'`(lead 1) 백테스트, 날짜유형 「마지막 수요일(무료)」 229 개소·일의 값이다. 2025-01-29(마지막 수요일이자 설날)는 날짜유형에서 「명절 연휴」로 먼저 분류되므로 빠진다.
- C3, 마지막 수요일 229 개소·일, 확정 시점별:

| 확정 | 4주 권고의 | 적중률 | 실제 ÷ q0.8 | 실제 ÷ q0.5 |
|---|---|---|---|---|
| 전날 (lead 1) | 1주차 | 0.485 | 1.18 | 1.49 |
| 1주 전 (lead 8) | 2주차 | 0.537 | 1.15 | 1.53 |
| 2주 전 (lead 15) | 3주차 | 0.515 | 1.14 | 1.53 |
| 3주 전 (lead 22) | 4주차 | 0.607 | 1.11 | 1.54 |

- 지평이 길어져도 나빠지지 않는다. 어느 시점이든 실제가 중앙값의 약 1.5배 → **무료 효과를 작게 잡는 모형의 성질**이다.
- (정정) 앞선 대화에서 「0.52, 실제 ÷ q0.5 약 1.4배」라고 한 값은 2025-01-29 를 포함한 252 개소·일 기준이었다. 위 표가 보고서와 같은 기준이다.

3. Chronos-2 는 제로샷(파인튜닝 없음) — 입력된 과거 안에서 「1인 날 값이 얼마나 뛰었나」를 읽어 미래에 적용한다.
4. 예측 뒤 배수를 곱하는 사후 보정은 없다. 보정 A · B 도 정기 마지막 수요일은 건드리지 않는다.

### 2.3 「실수 5」 셀의 문제

현재 문장 (`tools/make_final_notebooks.py:129` 가 생성):

> `paid == 0` 을 무료 개방일로 보면 (2023~2025 개방일). 창덕궁은 무료일에도 유료를 기록하고, 왕릉은 무료가 아닌 날에도 `paid == 0` 이 많다. `paid` 는 그날이 지나야 아는 값이라 누수이기도 하다.

| 문제 | 확인한 사실 |
|---|---|
| 비판 대상이 교안 정의가 아님 | 교안 정의는 `paid / total < 0.15`. 이 정의로는 창덕궁 무료일도 잡힌다(무료일 유료 비중 중앙값 8.5%, 평소 63%). 「창덕궁은 `paid == 0` 으로 못 잡는다」는 15% 정의가 이미 해결한 문제 |
| 「왕릉은 무료 아닌 날도 0 이 많다(7.9%)」 | 양주온릉이 869일 전부 `paid == 0`(유료 기록 자체가 없음). 빼면 왕릉 2.5% — 궁 1.5%, 종묘 2.1% 와 비슷 |
| 남는 `paid == 0` 은 오류가 아님 | 2024-05-15 ~ 19, 2025-10-30 ~ 11-09 처럼 여러 개소가 같은 날 함께 0 → 달력 규칙 밖 **실제 무료 개방** |
| 「누수」 설명 | 과거 날짜를 `paid` 로 표시하는 것은 누수가 아니다. 문제는 **예측할 날의 `paid` 를 확정 시점에 알 수 없어 입력으로 쓸 수 없다**는 것 |
| 문장이 끊김 | 「…무료 개방일로 보면 (2023~2025 개방일).」 뒤에 무엇이 문제인지가 없다 |

같은 내용이 보고서 「확인한 실수와 크기」 표의 5번 행과 결정 10 에도 있다.
